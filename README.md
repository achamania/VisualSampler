## First launch / 初回起動

この版はDeveloper ID署名・Apple公証を受けていません。信頼する配布元からの入手を確認し、アプリを一度開いた後、「システム設定 → プライバシーとセキュリティ → このまま開く」から起動を許可します。詳細・警告別の対処は各READMEを確認してください。

This release is not Developer ID signed or notarized by Apple. After verifying that you trust the source, try opening the app once, then use System Settings → Privacy & Security → Open Anyway. Read the full instructions and warning-specific guidance in your language above.

[Apple official guidance](https://support.apple.com/ja-jp/102445)

## Banks

フォルダ選択を求められたら、BankAとBankBを含む親のBanksを選びます。選択した場所は保存されます。案内画面でRキーを押すと再選択できます。
When prompted, choose the parent Banks folder containing BankA and BankB. The location is saved. Press R on the guidance screen to retry selection.

## v2.0.0

- HEIC/HEIF画像と撮影方向の自動補正 / HEIC/HEIF photos with automatic orientation
- 3:4・4:3・9:16・16:9の4画角 / Four aspect ratios
- 画角切替時の緑色表示 / Green TV-style aspect ratio indicator
- 単一ウィンドウとMacの緑ボタンによる全画面 / Single window with macOS fullscreen
- 更新したBANK A/B画像32枚、5言語README / 32 updated bank images and guides in five languages

映像画面を左クリックして画角を切替。表示サイズは端をドラッグし、全画面は緑ボタンで操作します。
Left-click to change aspect ratio. Drag window edges to resize; use the green button for fullscreen.

Apple Silicon Mac専用。Intel Mac・Windows・動画ファイルには未対応です。
Apple Silicon Macs only. Intel Macs, Windows and video files are not supported.
